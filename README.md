## 🚀 Panduan Memasukkan Kod ke GitHub (Push to GitHub)

Ikuti langkah mudah ini untuk memuat naik kod ini ke akaun GitHub anda:

### Langkah 1: Buat Repositori Baru di GitHub
1. Log masuk ke akaun [GitHub](https://github.com).
2. Klik butang hijau **"New"** (atau ikon `+` di penjuru kanan atas -> **New repository**).
3. Masukkan nama repositori: `takaful-by-maybellin`.
4. Tetapkan sebagai **Public** (atau **Private** mengikut pilihan anda).
5. Jangan tandakan *Initialize this repository with README* (kerana kita sudah ada fail ini).
6. Klik **"Create repository"**.

### Langkah 2: Jalankan Perintah Git di Terminal Komputer Anda
Buka Terminal / Command Prompt di dalam folder projek ini dan taipkan:

```bash
# 1. Inisialisasi Git
git init

# 2. Tambah semua fail
git add .

# 3. Buat commit pertama
git commit -m "Pelancaran Takaful By Maybellin - Portal & Suite AI GETB"

# 4. Tetapkan branch utama kepada main
git branch -M main

# 5. Sambungkan ke repositori GitHub anda (Gantikan USERNAME dengan username GitHub anda)
git remote add origin https://github.com/USERNAME/takaful-by-maybellin.git

# 6. Tolak kod ke GitHub
git push -u origin main
```

## ⚡ Panduan Melancarkan (Launch / Deploy) di Vercel

Selepas kod anda berada di GitHub, anda boleh melancarkannya di Vercel dalam masa 2 minit secara **PERCUMA**:

1. Pergi ke [Vercel](https://vercel.com) dan daftar masuk menggunakan akaun GitHub anda.
2. Di papan pemuka (*Dashboard*), klik butang **"Add New..."** -> pilih **"Project"**.
3. Cari dan pilih repositori `takaful-by-maybellin` yang anda telah push tadi, kemudian klik **"Import"**.
4. Di bahagian konfigurasi projek (*Configure Project*):
   * **Framework Preset:** Pilih `Vite` (atau biarkan default Vercel automatik kesan).
   * **Root Directory:** `./` (default).
5. Buka tab **"Environment Variables"** dan tambah pembolehubah berikut:
   * **Key:** `GEMINI_API_KEY`
   * **Value:** Masukkan API Key Gemini anda (didapati percuma dari [Google AI Studio](https://aistudio.google.com)).
6. Klik butang **"Deploy"**.
7. Tunggu sekitar 1 minit. Vercel akan memberikan pautan laman web rasmi anda (contoh: `https://takaful-by-maybellin.vercel.app`) lengkap dengan sijil SSL percuma!
